# CSS examples

Open index.html in a browser. No installation needed.

Read the sentence above each example, then move the slider or resize the browser.

- index.html: text and examples
- style.css: styles
- app.js: three slider controls
- PRESENTER-NOTES.md: a short script

To serve locally, run `python3 -m http.server 8873 --bind 127.0.0.1` and open http://127.0.0.1:8873.
