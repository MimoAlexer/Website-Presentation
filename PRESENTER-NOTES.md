# Short presentation script

1. **px and %:** “The blue box has a fixed width. The green box takes half of its parent.” Move the slider. At 300px both are 150px wide. At 400px the green box is 200px wide.
2. **em and rem:** “For font-size, em uses the parent font size. rem uses the root font size.” Change the parent to 24px. The em text becomes 48px. The rem text stays 32px.
3. **vw:** “50vw means half the viewport width.” Resize the browser window to show the box changing.
4. **Opacity:** “Some CSS values do not need units.” Change opacity to 0.5, then 0. The element becomes invisible but still takes up space.

Finish: “The unit decides what a size is relative to.”
