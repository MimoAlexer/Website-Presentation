CSS-Werte und Einheiten

1. Ganzzahl

Der Wert 700 stellt den Text fett dar.

Einheitentyp: Einheitenlos — 700 ist eine Ganzzahl und weder eine absolute noch eine relative Einheit.

font-weight: 700;

Fetter Text

2. Schlüsselwort

Das Schlüsselwort center richtet den Text mittig aus.

Einheitentyp: Einheitenlos — center ist ein Schlüsselwort und weder eine absolute noch eine relative Einheit.

text-align: center;

Zentrierter Text

3. Funktion

Die Funktion rgb() erzeugt eine Farbe.

Einheitentyp: Einheitenlos — rgb() ist eine Farbfunktion und weder eine absolute noch eine relative Einheit.

background-color: rgb(255, 160, 120);
rgb-Farbe

4. Kombination

Ein Rahmenwert kombiniert eine Größe, einen Stil und eine Farbe.

Einheitentyp: px ist eine absolute Einheit.

border: 3px solid black;
Kombinierte Werte

5. px und %

Ändere die Breite des Elternelements. Der blaue Kasten bleibt 150px breit. Der grüne Kasten nimmt 50% der Breite des Elternelements ein.

Einheitentyp: px ist eine absolute Einheit; % ist eine relative Einheit.

.blue { width: 150px; }
.green { width: 50%; }
150px
50%

6. em und rem

Ändere die Schriftgröße des Elternelements. Der Text mit em verändert sich. Der Text mit rem verwendet die Schriftgröße des Wurzelelements.

Einheitentyp: px ist eine absolute Einheit; em und rem sind relative Einheiten.

html { font-size: 16px; }
.em { font-size: 2em; }
.rem { font-size: 2rem; }

Dieser Text ist 2em groß

Dieser Text ist 2rem groß

7. vw

Ändere die Größe des Browserfensters. Dieser Kasten ist immer halb so breit wie der Darstellungsbereich.

Einheitentyp: vw ist eine relative Einheit.

.viewport-box { width: 50vw; }
50vw

8. Einheitenlose Zahl

Die Deckkraft reicht von 0 (unsichtbar) bis 1 (vollständig sichtbar). Dabei wird auch der Text ausgeblendet.

Einheitentyp: Einheitenlos — Werte für die Deckkraft sind weder absolute noch relative Einheiten.

.fade { opacity: 1; }
