CSS-Werte und Einheiten

1. Pixel (px)

Der Kasten ist immer 150 Pixel breit.

Einheitentyp: px ist eine absolute Einheit.

.px-box { width: 150px; }
150px

2. Zentimeter (cm)

Der Kasten ist zwei CSS-Zentimeter breit.

Einheitentyp: cm ist eine absolute Einheit.

.cm-box { width: 2cm; }
2cm

3. Millimeter (mm)

Der Kasten ist 20 CSS-Millimeter breit.

Einheitentyp: mm ist eine absolute Einheit.

.mm-box { width: 20mm; }
20mm

4. Punkt (pt)

Diese Schrift ist 18 Punkt groß.

Einheitentyp: pt ist eine absolute Einheit.

.pt-text { font-size: 18pt; }

Schriftgröße: 18pt

5. Prozent (%)

Ändere die Breite des Elternelements. Der grüne Kasten nimmt immer 50 Prozent davon ein.

Einheitentyp: % ist eine relative Einheit.

.percent-box { width: 50%; }
50%

6. em und rem

Ändere die Schriftgröße des Elternelements. Der Text mit em verändert sich mit. Der Text mit rem richtet sich nach dem Wurzelelement.

Einheitentyp: em und rem sind relative Einheiten.

html { font-size: 16px; }
.em { font-size: 2em; }
.rem { font-size: 2rem; }

Dieser Text ist 2em groß

Dieser Text ist 2rem groß

7. Viewport-Breite (vw)

Ändere die Größe des Browserfensters. Dieser Kasten ist immer halb so breit wie der Darstellungsbereich.

Einheitentyp: vw ist eine relative Einheit.

.viewport-width-box { width: 50vw; }
50vw

8. Viewport-Höhe (vh)

Dieser Kasten ist zehn Prozent der Höhe des Browserfensters hoch.

Einheitentyp: vh ist eine relative Einheit.

.viewport-height-box { height: 10vh; }
10vh
