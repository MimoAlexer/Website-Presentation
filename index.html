CSS values and units

1. Integer

The value 700 makes the text bold.

font-weight: 700;

Bold text

2. Keyword

The keyword center moves the text to the center.

text-align: center;

Centered text

3. Function

The rgb() function makes a color.

background-color: rgb(255, 160, 120);
rgb color

4. Combination

A border value combines a size, style and color.

border: 3px solid black;
Combined values

5. px and %

Resize the parent. The blue box stays 150px wide. The green box takes 50% of the parent.

.blue { width: 150px; }
.green { width: 50%; }
150px
50%

6. em and rem

Change the parent font size. The em text changes. The rem text uses the root font size.

html { font-size: 16px; }
.em { font-size: 2em; }
.rem { font-size: 2rem; }

This is 2em

This is 2rem

7. vw

Resize the browser window. This box is always 50% of the viewport width.

.viewport-box { width: 50vw; }
50vw

8. A number without a unit

Opacity goes from 0 (invisible) to 1 (fully visible). It fades the text too.

.fade { opacity: 1; }
Hello!
